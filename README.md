# 📊 Finance Analytics Dashboard | Power BI

An interactive **Finance Analytics Dashboard** built in **Power BI** to analyze financial transactions, customer behavior, transaction performance, operational fees, taxes, and Year-over-Year (YoY) growth. This dashboard enables stakeholders to monitor KPIs, identify business trends, and make data-driven financial decisions.

---

## 📌 Project Overview

The dashboard was developed based on business requirements for a financial organization to provide a centralized analytics solution for monitoring financial performance across multiple dimensions.

It allows users to:

- Monitor key financial KPIs in real time
- Analyze monthly transaction trends
- Compare successful, failed, and pending transactions
- Evaluate customer segment performance
- Identify top-performing states
- Analyze transaction types and profitability
- Understand customer demographics
- Perform Year-over-Year (YoY) analysis
- Drill down into detailed transaction records

---

## 🎯 Business Objectives

The dashboard helps stakeholders answer important business questions such as:

- How are financial transactions growing over time?
- Which customer segments contribute the most?
- Which states generate the highest transaction amount?
- What is the success rate of transactions?
- Which transaction types generate the highest revenue?
- How much fees and taxes are collected?
- How does performance compare with the previous year?

---

# 📈 Key Performance Indicators (KPIs)

| KPI | Description |
|------|-------------|
| 💰 Total Amount | Total transaction amount processed |
| 🔄 Total Transactions | Total number of transactions |
| 📊 Average Transaction Value | Average value per transaction |
| 💳 Total Fees | Total fees collected |
| 🧾 Total Tax | Total tax generated |
| 📈 YoY Growth | Year-over-Year comparison for KPIs |
